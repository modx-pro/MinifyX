# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0-pl] - 2026-07-27

### Added
- Pure-PHP asset pipeline with PSR-4 namespace `MinifyX\`.
- Atomic filesystem cache with source fingerprinting and warm-cache short-circuit.
- Modern processors for CSS/JS minify, SCSS, LESS, and image transforms.
- Safe HTML minifier that preserves `pre`, `textarea`, `script`, `style`, and conditional comments.
- Registered-assets parser that keeps tag attributes (`defer`, `async`, `type="module"`, `integrity`, `media`, …).
- Image endpoint hardening: path whitelist (directory-boundary), pixel/byte/dimension limits, ETag/`304`, HMAC signing enforced when key is set.
- Characterization, security, and processor PHPUnit suite plus PHPStan level 8 and GitHub Actions CI.
- System settings `minifyx_connector`, `minifyx_image_signing_key`, `minifyx_image_max_pixels`, `minifyx_image_max_bytes`.

### Changed
- Platform requirements: MODX 2.8.x+ on PHP 7.4+; MODX 3.x on PHP 8.2+.
- Compatible with MODX 2.8+ and MODX 3.x through a legacy `modX` adapter.
- Snippet, `minify()`, groups, hooks, and connector URL keep the 1.x public contract in compatibility mode.
- Cache keys now include source mtimes and post-hook content.
- Snippet and plugin share `processFiles()` / `processAndSave()` (same cache, hooks, and write gates).
- Bundled registered assets keep attributes from the first tag only and drop `integrity`/`crossorigin`.

### Removed
- Dependency on Munee and its abandoned transitive packages (`jshrink`, `leafo/scssphp`, `oyejorge/less.php`, `imagine` 0.7, CoffeeScript packager).
- Git submodule `core/components/minifyx/munee`.

### Deprecated
- Runtime CoffeeScript compilation is isolated behind `LegacyCoffeeCompiler` and will be removed in 3.0. Prefers precompiled `.js`.

### Dependencies
- `matthiasmullie/minify` ^1.3.75
- `scssphp/scssphp` ^2.0
- `wikimedia/less.php` ^5.0
- `intervention/image` ^3.11

### Fixed
- Sibling-prefix path bypass in PathGuard/FileNormalizer (`/web` vs `/web-backup`).
- Cache filename path traversal via `jsFilename`/`cssFilename`.
- Empty or failed compiles no longer publish cache files.
- Post-hooks sync content on the processAndSave host before write.
- SCSS/LESS query-string variables reach compilers.
- Image resize requests above max dimension rejected; HMAC is a real gate when key is configured.
- `reset()` / `minify()` now sync `.min.js` / `.min.css` extensions.
- `prepareFiles()` no longer mutates `$_GET`.
- `print` registration returns both CSS and JS tags.
- Empty cache writes are no longer treated as failures.
- Plugin uses `$modx` instead of invalid `$this->modx` for cache errors.
- Image rewrite is a single pass over HTML instead of repeated full-document `str_replace`.

## [1.6.0-pl] - 2018-01-22

### Added
- `MinifyX::getFileUrl()` method.
- `MinifyX::getFilePath()` method.
- `forceUpdate` snippet parameter and system setting.
- `forceDelete` system setting for deleting all files from the cache directory.
- `cssTpl` and `jsTpl` snippet parameters.
- `print` registration type for immediate output.
- `fixVm.php` file hook for fixing `vmax` and `vmin` units after CSS compilation.

### Changed
- Minimum PHP version raised to 5.6.

### Fixed
- Various minor issues.

### Dependencies
- Updated Munee and its dependencies.

## [1.5.0-pl] - 2018-01-19

### Added
- Group configuration file at `core/components/minifyx/config/groups.php`.
- `cssGroup` and `jsGroup` snippet parameters.
- `preHooks` and `hooks` snippet parameters. A hook can be a snippet or a file in `core/components/minifyx/hooks`.
- Support for running the snippet multiple times.
- `cssToPage.php` file hook, available through `&hooks=cssToPage.php`.
