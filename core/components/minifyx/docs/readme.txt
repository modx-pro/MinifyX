--------------------
MinifyX
--------------------
Version: 3.0.0-pl
--------------------

MinifyX is a MODX® Revolution addon that combines, compiles and minifies JS and CSS files, with optional image transforms and HTML minify.

Requirements:
- MODX 3.x
- PHP 8.2+
